Como instalar o Cupom Livre no Chrome

O Cupom Livre funciona em navegador Chrome de computador. Depois de instalado, você pode usar a extensão para coletar cupons disponíveis do Mercado Livre com 1 clique.

Instalar extensão grátis
1

Abra no computador

Use o Chrome ou navegador compatível com extensões do Chrome. A extensão não funciona em celular.

2

Adicione ao Chrome

Clique em instalar pela Chrome Web Store e confirme a adição da extensão ao navegador.

3

Colete cupons

Entre no Mercado Livre pelo computador e use o Cupom Livre para coletar cupons disponíveis.

Está acessando pelo celular?

Envie este link para você mesmo e abra depois no computador. O foco da extensão é o uso no Chrome desktop, onde ela consegue executar a coleta de cupons disponíveis.
